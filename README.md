## Описание проекта

Двумерная аркадная игра «Астероиды», разработанная
на языке Python с использованием библиотеки Pygame.

Игрок управляет космическим кораблём, уничтожает
астерoиды, набирает очки и старается сохранить жизни.

## Цель работы

Освоение объектно-ориентированного проектирования,
тайловой анимации изображений и реализации
взаимодействия игровых объектов.

## Функциональные возможности

### Основной функционал

- Стартовая заставка игры.
- Управление космическим кораблём.
- Вращение и ускорение корабля.
- Инерция и постепенное замедление.
- Изменение изображения при включении двигателя.
- Стрельба ракетами.
- Ограниченное время жизни ракет.
- Случайная генерация астероидов.
- Вращение и перемещение астероидов.
- Тороидальная геометрия игрового поля.
- Обработка столкновений.
- Анимация взрывов.
- Подсчёт очков.
- Система жизней.
- Завершение и повторный запуск игры.
- Неподвижный и динамический полупрозрачный фон.

## Требования к системе

- Python 3.10 или выше.
- Библиотека Pygame.
- Windows, macOS или Linux.
- Git.

Версии зависимостей указываются в requirements.txt.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/lxskx/PPPLab3.git
cd PPPLab3
```

### 2. Создание виртуального окружения

macOS и Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

Windows:

```bat
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск игры

```bash
python main.py
```

## Управление

| Клавиша | Действие |
|---|---|
| Стрелка влево | Вращение против часовой стрелки |
| Стрелка вправо | Вращение по часовой стрелке |
| Стрелка вверх | Включение двигателя |
| Space | Выстрел |
| Esc | Выход из игры |
| Левая кнопка мыши | Запуск игры через заставку |

## Объектно-ориентированное проектирование

### Game

Управление состоянием игры, игровым циклом,
обработкой событий и подсчётом очков.

### GameObject

Базовый класс игровых объектов.
Содержит координаты, скорость, угол поворота
и методы перемещения.

### Ship

Класс космического корабля.
Реализует управление, ускорение и вращение.

### Asteroid

Класс астероида.
Реализует движение и вращение объекта.

### Missile

Класс ракеты.
Реализует движение и ограниченное время жизни.

### Explosion

Класс анимации взрыва.

## Пример использования

1. Запустить программу.
2. Нажать мышью на стартовую заставку.
3. Управлять кораблём с помощью стрелок.
4. Уничтожать астероиды нажатием Space.
5. Получать одно очко за каждый уничтоженный астероид.
6. Избегать столкновений с астероидами.
7. После завершения игры начать новую попытку.
