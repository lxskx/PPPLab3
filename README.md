## Описание проекта

Проект представляет собой двумерную аркадную игру
«Астероиды», разработанную на языке Python
с использованием библиотеки Pygame.

Игрок управляет космическим кораблём, уничтожает
астероиды, набирает очки и старается сохранить жизни.

## Цель работы

Освоение объектно-ориентированного проектирования,
тайловой анимации изображений, обработки событий
и взаимодействия игровых объектов.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/lxskx/PPPLab3.git
cd PPPLab3
```

### 2. Создание виртуального окружения

macOS и Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

Windows:

```bat
python -m venv venv
venv\Scripts\activate
```

При несовместимости опубликованного виртуального окружения
с операционной системой необходимо создать локальное
окружение заново.

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск игры

```bash
python main.py
```

## Управление

| Клавиша | Действие |
|---|---|
| Стрелка влево | Вращение корабля влево |
| Стрелка вправо | Вращение корабля вправо |
| Стрелка вверх | Включение двигателя |
| Space | Выстрел ракетой |
| Esc | Выход из игры |
| Левая кнопка мыши | Запуск игры через заставку |

## Правила игры

В начале игры игрок имеет три жизни и ноль очков.

За каждый уничтоженный астероид начисляется одно очко.

При столкновении корабля с астероидом количество жизней
уменьшается, а корабль возрождается неподвижным
в центре игрового поля.

Если на момент столкновения количество жизней равно нулю,
игра завершается согласно условиям задания.

На экране появляется заставка завершения игры.
Последний счёт сохраняется до начала новой попытки.

Астероиды не сталкиваются между собой.

## Объектно-ориентированное проектирование

### Game

Управляет игровым окном, событиями, игровым циклом,
генерацией астероидов, обработкой столкновений,
подсчётом очков и состояниями игры.

### GameObject

Базовый класс движущихся объектов.

Содержит координаты, вектор скорости, угол поворота,
угловую скорость и радиус столкновения.

Реализует перемещение, вращение, отображение объектов
и переход через границы игрового поля.

### Ship

Наследуется от GameObject.

Реализует управление кораблём, вращение,
ускорение и постепенное замедление.

Содержит два изображения корабля:
с выключенным и включённым двигателем.

### Asteroid

Наследуется от GameObject.

Реализует случайную генерацию размера, изображения,
линейной и угловой скорости астероида.

### Missile

Наследуется от GameObject.

Создаётся в носовой части корабля, движется
с постоянной скоростью и имеет ограниченное время жизни.

### Explosion

Реализует покадровую анимацию взрыва
на основе спрайтового изображения из 12 кадров.

## Математическая модель

### Перемещение

Положение объекта изменяется пропорционально
его скорости и прошедшему времени:

position = position + velocity * dt

### Ускорение

Скорость корабля увеличивается в направлении
его текущей ориентации.

При выключенном двигателе применяется
коэффициент сопротивления среды.

### Тороидальная геометрия

Координаты объектов вычисляются по модулю
ширины и высоты игрового поля:

x = x % WIDTH
y = y % HEIGHT

Это обеспечивает непрерывное движение объектов
через противоположные границы экрана.

### Столкновения

Столкновение определяется по расстоянию
между центрами двух объектов.

Если расстояние меньше или равно сумме
радиусов объектов, фиксируется столкновение.

При расчёте учитывается тороидальная геометрия.

### Время жизни ракет

Скорость ракеты составляет 520 пикселей в секунду,
а время жизни — 0,9 секунды.

Максимальная дальность полёта:

520 * 0,9 = 468 пикселей.

Полученное значение меньше минимального размера
игрового поля, равного 700 пикселям.

## Графические ресурсы

Все изображения игровых объектов создаются
программными средствами Pygame.

Звёздный фон является неподвижным.
Второй полупрозрачный фоновый слой движется влево.

Для непрерывного движения фонового слоя используются
два одинаковых соседних изображения.

Анимация взрыва использует спрайтовое изображение
размером 1152 на 96 пикселей.

Изображение содержит 12 последовательных кадров
размером 96 на 96 пикселей.

Сторонние графические ресурсы не используются.
